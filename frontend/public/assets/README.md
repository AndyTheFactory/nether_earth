# Visual assets

`manifest.json` maps semantic ids (see `src/render/assets.ts`, `SemanticAsset`)
to image files in this directory. Any id without an entry renders as a
procedural placeholder prism in the ZX Spectrum palette.

Provenance policy: every image added here must be listed below with its
origin. No original ZX Spectrum graphics are redistributed; recreations must
follow the original's visual character (2:1 dimetric blocks, Spectrum colours),
not a modern RTS restyle.
